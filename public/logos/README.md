# Logos officiels de conformité

Déposez ici les fichiers de logos **officiels** (SVG de préférence, sinon PNG
transparent). Ils s'affichent automatiquement dans le bandeau « Conçu pour la
conformité du secteur public » de la page d'accueil (rendu en niveaux de gris,
puis en couleur au survol).

Tant qu'un fichier est absent, un badge maison s'affiche en repli.

## Fichiers attendus (mêmes noms exactement)

| Fichier            | Logo                          |
| ------------------ | ----------------------------- |
| `cnil.svg`         | CNIL                          |
| `iso-27001.svg`    | ISO / ISO 27001               |
| `rgpd.svg`         | RGPD / GDPR                   |
| `ia-act.svg`       | EU AI Act / emblème européen  |

> ⚠️ Ces logos sont des **marques déposées**. Utilisez uniquement les fichiers
> obtenus depuis les sources officielles (CNIL, ISO, Commission européenne) et
> respectez leurs conditions d'usage. Le code se contente d'afficher les
> fichiers que vous fournissez ici — il ne reproduit aucune marque.

Pour ajouter / retirer une entrée, modifiez le tableau `COMPLIANCE` dans
`components/landing/landing-page.tsx`.
